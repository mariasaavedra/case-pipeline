| Word | Means |
|---|---|
| **Fee K** | A fee contract, on the Fee Ks board in Monday. *Pending* until paid, then *Paid Fee Ks*. |
| **AF / FF / PF** | Attorney Fee, Filing Fee, Processing Fee. AF and PF go to Operating, FF to Trust. |
| **PS Stage** | Prescheduling stage of a Paid Fee K. |
| **Open Form** | A USCIS form we're preparing, on the Open Forms board. |
| **E-File** | The client's case folder in SharePoint. **CC** = client copies, **CAF** = client-sent files. |
| **Consult folder** | The client's SharePoint folder from their consult, before they're hired. |
| **E&A** | Emails & Activities, the timeline on a Monday item. |
| **North Pole** | Parked: a case set aside on purpose. Hidden from most lists unless you turn it on. |
| **DMS** | Innovation Law Lab's case database; cases up to 2024. |
| **Screen code** | P (page), M (popup), D (dropdown), G (global) codes on every screen. |
