## New: attachments and links on notes

You asked whether notes could show their attachments and links. Both now work.

**What we found.** Real file attachments in Monday.com live on *notes/updates* —
we confirmed against live data that about **1 in 4 notes has an attachment** (for
example, an 8 MB DACA renewal PDF). Emails in the activity timeline don't carry
files the same way; there, attachments come through as **links inside the message
text**. So the feature has two halves:

- **Attachments** — a note's files now appear as small chips beneath it
  (📎 filename · size). Clicking one opens the file in Monday.com (you'll need to
  be signed into Monday, which staff already are).
- **Links** — any web address in a note or email is now a clickable link instead
  of plain text. This also covers the email attachments that arrive as links.

**When you'll see it.** Two phases:

- **Links: immediately** after the deploy — that's just how the text is displayed,
  no data refresh needed.
- **Attachment chips: after the next overnight refresh.** The update adds the
  storage for attachments, but the files for *existing* notes get pulled in on the
  next full refresh (tonight at 1 AM). New notes show their attachments right away.
  So the chips will be there tomorrow morning.
