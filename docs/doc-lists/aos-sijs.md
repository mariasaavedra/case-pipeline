# Documents for I-485: SIJS Adjustment

## English

- [ ] 2 passport size photographs
- [ ] I-360 approval
- [ ] Birth certificate
- [ ] Photo ID. Example: Passport
- [ ] Criminal records (traffic included). Include the charging document and the disposition. Must be court certified.
- [ ] Medical Exam (Form I-693, in the sealed envelope). It must be filed together with the I-485.

## Español

- [ ] 2 fotografias tamano pasaporte
- [ ] Aprobacion de I-360
- [ ] Certificado de nacimiento
- [ ] ID con photo; ejemplo pasaporte
- [ ] Antecedentes penales (trafico incluido). Incluya el document de carga y la disposicion. Debe estar certificado por el tribunal.
- [ ] Examen Medico (Formulario I-693, en el sobre sellado). Debe presentarse junto con el I-485.
